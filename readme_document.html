5. Key Features Implemented
  • Department Filtering: Instant tabbed filtering across CSE, ECE, Mechanical, Civil, Exam Cell, Placement Cell, and All Departments.
  • Live Keyword Search: Real-time search through titles, descriptions, and circular contents.
  • Role-Based Access Control: Interactive modal allowing instant switching between Admin and Student mode with auto-fill demo credentials.
  • Notice Management: Admin portal for publishing and deleting circulars.
  • Responsive UI: Mobile-friendly, tablet-optimized layout built with React and custom CSS.
6. Tech Stack Used
  • Frontend: React.js (Hooks: useState, useEffect)
  • Styling: Pure CSS3 (Flexbox & CSS Grid)
  • Build Tool: Vite
  • Cloud Hosting: Render (Static Site)
  • Version Control: Git & GitHub
